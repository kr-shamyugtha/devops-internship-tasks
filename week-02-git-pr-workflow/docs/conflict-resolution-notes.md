# Merge Conflict Resolution Notes

## Conflict Overview

A merge conflict occurred in `app-config.txt` because both the `main` branch and `feature/week-02-git-workflow` modified the same configuration lines.

## Cause

The `Version` and `Review Status` fields were updated differently in both branches.

## Resolution Process

1. Reviewed conflicting changes from both branches.
2. Compared updates in `main` and feature branch.
3. Combined relevant changes logically.
4. Removed Git conflict markers.
5. Verified final configuration.

## Final Outcome

The merge conflict was resolved successfully by preserving both the feature update and security update.
